# UI Design Mini-Project

## Overview

This project was created for **SOEN 357: User Interface Design**.

The goal of the project is to design and develop a website that presents a complete UX/UI case study. The website documents the main stages of the design process, including user research, journey mapping, wireframing, prototyping, and usability testing.

Although this type of project is often completed in teams, this project was completed independently.

## Project Objectives

The main objectives of this project are to:

* Identify the needs, goals, and challenges of the target users.
* Apply user-centered design principles.
* Create clear user personas and journey maps.
* Design wireframes and interactive prototypes.
* Develop a website that presents the design process and results.
* Evaluate the interface using usability and human-computer interaction principles.

## Design Process

### 1. User Research

User research was conducted to understand the target audience and their needs.

This stage included:

* Identifying user goals.
* Identifying common pain points.
* Studying user behaviours and expectations.
* Creating detailed user personas.
* Defining the main problem that the interface should solve.

### 2. User Personas

User personas were created based on the research findings.

Each persona describes important user characteristics, such as:

* Background.
* Goals.
* Needs.
* Motivations.
* Frustrations.
* Technical experience.

The personas helped guide the design decisions throughout the project.

### 3. Journey Mapping

User journey maps were created to visualize how users interact with the proposed interface.

The journey maps include:

* User actions.
* User goals.
* Important tasks.
* Possible challenges.
* User emotions.
* Opportunities for improving the experience.

### 4. Wireframing

Wireframes were created to define the structure and layout of the website before implementing the final visual design.

The wireframes focus on:

* Page organization.
* Content hierarchy.
* Navigation.
* Buttons and interactive elements.
* User flows.
* Accessibility and ease of use.

### 5. Visual Design

The visual design defines the overall appearance of the interface.

The design system includes:

* Colour palette.
* Typography.
* Spacing.
* Buttons.
* Icons.
* Images.
* Reusable interface components.

The visual choices were made to keep the interface clear, consistent, and easy to understand.

### 6. Prototyping

A clickable prototype was developed to demonstrate how users would interact with the interface.

The prototype includes:

* Navigation between screens.
* Main user tasks.
* Interactive buttons.
* Form interactions.
* Important user flows.
